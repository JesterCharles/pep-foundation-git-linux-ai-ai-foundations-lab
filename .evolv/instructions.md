# AI Foundations — Code lab

Review an AI assistant's proposed change like a teammate would: write testable acceptance criteria, check its claims against the real diff, decide, and make a help request safe to send.

- **Edit:** the Markdown answer files in `src/review-desk/work/`. `TODO` and `your-verdict` placeholders mark what to fill in.
- **Run the tests:** **Run Tests** in Exa Studio, or `pip install -r requirements.txt` then `python -m pytest -q`. All 3 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: `README.md` in the project folder.
